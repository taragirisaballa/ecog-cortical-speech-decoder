# Dataset Notes: Human ECoG speaking consonant-vowel syllables

DANDI `000019` contains human ECoG recordings collected during consonant-vowel syllable production. This dataset is useful for practicing NWB inspection, ECoG preprocessing, high-gamma feature extraction, and simple speech-decoding baselines.
